TCP Port Scanner

A multithreaded TCP port scanner written in Python using socket programming.

Features

- Scan a single host
- Scan a range of ports
- Multithreaded scanning
- Exception handling
- Result logging to file
- Console output

Requirements

- Python 3.x

Usage
i save the code eith port_scanner.py
Run:

python3 port_scanner.py

Enter:

- Hostname or IP address
- Start port
- End port

Example:

Host: 127.0.0.1
Start Port: 1
End Port: 100

Results are displayed on screen and saved to "scan_results.txt".

Concepts Used

- TCP Sockets
- Multithreading
- File Handling
- Exception Handling
